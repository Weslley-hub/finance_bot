# Como contribuir

O Finlar é um projeto de [Weslley Fernando Teixeira Chaves](https://github.com/Weslley-hub).
Fork, pull request e commit de outras pessoas são bem-vindos. A autoria do projeto continua sendo dele.

## Fluxo

1. Faça um **fork** do repositório.
2. Crie um branch a partir de `main` (`git checkout -b descricao-da-mudanca`).
3. Faça commits pequenos, em português, dizendo o porquê da mudança.
4. Abra um **pull request** para `main` e explique o que mudou e como testar.

## Regras

- Não commite `.env`, tokens, chaves ou dados da família.
- Mantenha o aviso de copyright e o arquivo `LICENSE` (MIT).
- Não altere o autor do projeto nem a licença sem conversar antes.
- Ao abrir o PR, você concorda que a contribuição entra sob a licença MIT.

## Depois que o PR entrar

O histórico do Git guarda o seu nome no commit. Isso não transfere a autoria do Finlar — só registra a sua contribuição.
